# 模型管理

本目录用于存放本地推理所需的模型文件。

## 支持的模型

| 模型 | 用途 | 格式 | 推荐大小 |
|------|------|------|----------|
| Qwen2.5-7B | 通用对话 | GGUF | ~4GB (Q4) |
| Whisper Base | 语音识别 | GGML | ~142MB |
| Piper zh-CN | 语音合成 | ONNX | ~60MB |

## 下载

```bash
bash download.sh all
```

## 注意事项

- 模型文件较大，不纳入 Git 版本控制
- 首次运行时会自动提示下载
- 支持自定义模型路径（在设置中配置）
