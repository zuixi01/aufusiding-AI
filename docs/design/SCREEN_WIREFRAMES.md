# Prometheus AI — 全屏 ASCII Wireframe 合集

> 版本: 1.0 | 日期: 2026-03-22 | 状态: 设计稿

---

## 一、概述

本文档收录 Prometheus AI 操作系统全部核心界面的 ASCII Wireframe。
Prometheus 不是聊天机器人——它是一个 **AI Operating System**，主屏以 3D 机器人 Avatar
为中心，8 个 App 图标环绕其周围，构成类似行星轨道的交互布局。

### 线框图约定

| 符号 | 含义 |
|------|------|
| `┌┐└┘│─` | 容器 / 卡片边框 |
| `╭╮╰╯` | 圆角容器 / 按钮 |
| `[文字]` | 可点击按钮 / 图标入口 |
| `●` | 机器人眼睛 |
| `≋` | 音频波形 |
| `◉` | 当前激活步骤 |
| `○` | 未完成步骤 |
| `✓` | 已完成步骤 |
| `░` | 进度条填充 |
| `━` | 分隔线 / Dock 栏 |
| `▸` | 可展开 / 更多 |
| `⋮` | 更多菜单 |
| `←` | 返回导航 |
| `✕` | 关闭 |
| `▶` | 发送 / 播放 |

### 设计原则

1. **Avatar 中心制** — 机器人始终是视觉焦点，App 围绕它分布
2. **沉浸式详情** — 点击任何 App 图标进入全屏沉浸页，非弹窗
3. **模式自适应** — Sleep / Driving / Work / Focus / Default 五种模式改变布局密度
4. **响应式** — Mobile (390px) 与 Desktop (1440px) 两套主屏布局

### 配色方案参考（不在线框中体现）

- 主背景: Ambient Cream `#FDF6EC` (Light) / `#1A1410` (Dark)
- 强调色: Ambient Gold `#D4A853`
- 机器人光晕: 跟随模式强调色 (Home 金 / Work 橄榄 / Sleep 紫 / Driving 琥珀 / Focus 铜)
- 危险 / 告警: Ember `#E8734A`

### 图标方案

- 图标库: **Phosphor Icons** duotone 风格
- 8 个核心 App 图标: `ph-robot` / `ph-microphone` / `ph-house` / `ph-brain` / `ph-shield-check` / `ph-puzzle-piece` / `ph-toolbox` / `ph-signpost`
- 线框中以 emoji 标注（🤖🎙🌐🧠🛡🔌🧩🧭），实际实现使用 Phosphor 图标

## 二、主屏 — AI 操作系统桌面

主屏是 Prometheus 的核心界面。3D 机器人 Avatar 居中，8 个功能 App
以环形轨道排列在其周围，底部固定 Dock 栏提供快捷操作。

### 3.1 🤖 Agent 集群

- 左滑任务卡片可取消 / 暂停任务

## 七、模式特殊布局

Prometheus 支持 5 种模式，每种模式改变界面密度、配色和信息优先级。

### 7.1 Sleep 模式

极简暗色界面，仅显示时间和闹钟。屏幕亮度自动降至最低，
机器人闭眼表示系统进入低功耗状态。

```
┌──────────────────────────────────┐
│                                  │
│                                  │
│                                  │
│            2:47                  │  ← 超大时间显示
│             AM                   │     字体: 72pt, 低亮度白
│                                  │
│         ╭──────╮                │
│         │ ◉◉   │  (闭眼微光)    │  ← 机器人闭眼状态
│         │ ───  │                │     微弱呼吸灯效果
│         ╰──────╯                │
│                                  │
│          ⏰ 7:00 AM              │  ← 下一个闹钟
│                                  │
│       环境: 🌡 22°C  💧 55%     │  ← 环境信息（极低亮度）
│                                  │
│                                  │
│                                  │
│  ─ ─ ─ 轻触唤醒 ─ ─ ─ ─ ─ ─ ─ │  ← 唤醒提示（几乎不可见）
└──────────────────────────────────┘
```

**Sleep 模式规则:**
- 所有通知静音，仅紧急联系人来电可穿透
- 屏幕亮度 ≤5%，纯黑背景
- 机器人呼吸灯频率: 4 秒/次（模拟睡眠呼吸）
- 轻触屏幕显示时间 5 秒后自动熄灭
- 闹钟触发时机器人「睁眼」动画 + 渐亮灯光

### 7.2 Driving 模式

大触控目标（最小 64px），高对比度配色，信息极度精简。
仅保留导航、通话和媒体三个核心功能。

```
┌──────────────────────────────────┐

│                                  │
│  ┌────────────────────────────┐  │
│  │                            │  │

│  │    ╱  ●    ●    ╲         │  │
│  │   │   ╭────╮    │         │  │
│  │   │   │ ── │    │         │  │
│  │    ╲  ╰────╯   ╱          │  │
│  │     ╰──────────╯           │  │
│  │   "路况良好，预计 25 分钟"  │  │
│  │                            │  │
│  └────────────────────────────┘  │
│                                  │
│  ┌──────────┐  ┌──────────┐    │
│  │          │  │          │    │
│  │  🗺 导航  │  │  📞 通话  │    │  ← 64px 大按钮
│  │          │  │          │    │
│  └──────────┘  └──────────┘    │
```

**Driving 模式规则:**
- 所有触控目标 ≥64px，间距 ≥16px
- 高对比度: 白色文字 + 深色背景，对比度 ≥7:1
- 禁止需要阅读的长文本，所有信息语音播报
- 语音交互为主要输入方式，自动激活
- 来电自动切换为车载免提模式

### 7.3 Work 模式

日历和任务突出显示，中等信息密度。
机器人表情切换为专注状态，界面偏向效率优化。

**Work 模式规则:**
- 日历和任务列表占据主要视觉区域
- 机器人缩小至角落，显示下一个日程提醒
- 通知仅显示工作相关（邮件、日历、协作工具）
- 社交媒体和娱乐通知自动静音
- 番茄钟集成: 25 分钟工作 + 5 分钟休息循环

### 7.4 Focus 模式

极简界面，通知完全静音。仅保留当前专注任务和计时器，
帮助用户进入深度工作状态。

```
┌──────────────────────────────────┐
│  🎯 Focus         🔕 已静音     │
│                                  │
│                                  │
│                                  │
│         ╭──────────╮             │
│        ╱  ● ── ●    ╲           │  ← 机器人专注表情

│       │   │ ──── │   │          │

│         ╰──────────╯             │
│                                  │
│          专注中...                │
│                                  │
│       ┌──────────────┐          │
│       │              │          │
│       │    47:23     │          │  ← 专注计时器
│       │   / 60:00    │          │     大字体居中
│       │              │          │
│       └──────────────┘          │
│                                  │
│  当前任务: 完成 Q1 报告           │
│                                  │
│                                  │
│                                  │
│       ╭──────────────╮          │
│       │  ⏸ 暂停专注  │          │  ← 唯一操作按钮
│       ╰──────────────╯          │
└──────────────────────────────────┘
```

**Focus 模式规则:**
- 所有通知静音，状态栏显示 🔕 标记
- 仅显示当前专注任务和倒计时
- 机器人表情为「专注」状态（微眯眼）
- 屏幕边缘无任何可点击元素，防止误触
- 专注结束时机器人「微笑」+ 成就统计弹窗
- 紧急中断需长按 3 秒确认退出
