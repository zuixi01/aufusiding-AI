# 架构说明

## 整体架构

Prometheus 采用分层架构，核心引擎用 Rust 实现，通过 UniFFI 桥接到各平台原生 UI。

```
┌─────────────────────────────────────────┐
│           原生 UI 层                      │
│  macOS (SwiftUI) │ iOS (SwiftUI)         │
│  Android (Compose) │ Desktop (Tauri)     │
├─────────────────────────────────────────┤
│           UniFFI 绑定层                   │
├─────────────────────────────────────────┤
│           Rust 核心引擎                   │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 智能路由 │ │ 对话管理  │ │ 记忆系统  │ │
│  └─────────┘ └──────────┘ └──────────┘ │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 本地推理 │ │ 云端 API  │ │ 插件系统  │ │
│  └─────────┘ └──────────┘ └──────────┘ │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ │
│  │ 语音引擎 │ │ IoT 控制  │ │ 安全系统  │ │
│  └─────────┘ └──────────┘ └──────────┘ │
├─────────────────────────────────────────┤
│           存储层 (SQLite + SQLCipher)     │
└─────────────────────────────────────────┘
```

## 数据流

1. 用户输入 → 智能路由器（意图分类）
2. 路由器 → 本地推理 / 云端 API
3. 推理结果 → 记忆系统（更新上下文）
4. 最终响应 → UI 层展示

## 安全模型

- 所有数据本地加密存储（SQLCipher）
- 多设备同步采用 E2E 加密
- 插件运行在 WASM 沙箱中
- 敏感信息存储在安全金库
